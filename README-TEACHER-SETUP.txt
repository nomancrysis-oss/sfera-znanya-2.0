КАБИНЕТ УЧИТЕЛЯ — ЭТАП 1

1. Загрузите содержимое архива в тот же репозиторий GitHub (замените существующие файлы).
2. В СУЩЕСТВУЮЩЕМ проекте Supabase откройте SQL Editor и выполните supabase-modo-teacher.sql. Не удаляйте существующие таблицы.
3. В Authentication > Users создайте email/password пользователя-учителя или найдите уже созданного. Скопируйте его UUID (не пароль).
4. В SQL Editor выполните INSERT INTO public.modo_teachers(user_id) VALUES ('UUID_УЧИТЕЛЯ') ON CONFLICT DO NOTHING; заменив UUID_УЧИТЕЛЯ настоящим UUID.
5. Проверьте Vercel Environment Variables: SUPABASE_URL и SUPABASE_PUBLISHABLE_KEY (публичный ключ), затем Redeploy при необходимости. Никаких секретных ключей на сайт не загружайте.
6. Откройте /modo-teacher.html и войдите под email/password учителя. Создайте класс и назначение.

ВАЖНО: это рабочий первый этап: вход, учительские классы и планирование назначений с безопасным RLS. Автоматический вход учеников по коду, проверка и запись результатов в Supabase ПОКА НЕ ПОДКЛЮЧЕНЫ. Существующий самостоятельный тренажёр продолжает работать без изменений.
