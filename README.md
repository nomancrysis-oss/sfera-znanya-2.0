## PISA/TIMSS — 20 вариантов
Добавлены 5 вариантов в каждом из 4 направлений. Источник каждого варианта — конкретный документ Google Диска. Для новых вариантов доступен интерактивный бланк ответов с локальным автосохранением и печатью; проверка ответов остаётся у учителя. Первый математический вариант дополнительно содержит автоматическую проверку 12 заданий. Для просмотра оригиналов нужны права доступа Google Drive и подключение к сети.
