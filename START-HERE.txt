СФЕРА ЗНАНИЙ / БІЛІМ АЯСЫ

1. Распакуйте архив.
2. Откройте start.html — подробную инструкцию.
3. Откройте index.html — приложение.

Достаточно обычного браузера. Ничего устанавливать не нужно.
Главный файл index.html можно использовать самостоятельно.

Изменения хранятся в вашем браузере. Делайте резервную копию:
Настройки и помощь → Скачать копию JSON.

Для передачи заполненного каталога:
Настройки и помощь → Скачать сайт с моим каталогом.

Другие HTML-файлы в архиве сохраняют переходы по старым именам страниц Tilda.
Их не нужно открывать для первого запуска.

Автоматическая общая база для нескольких учителей в эту версию не входит.
Объяснение публикации, работы с Tilda и проверки находится в start.html.
