СФЕРА ЗНАНИЙ — ОБЩИЙ КАТАЛОГ (Supabase)

1. Создайте проект на https://supabase.com (бесплатный тариф, если доступен).
2. Откройте SQL Editor и выполните supabase-setup.sql.
3. В Authentication → Providers включите Anonymous Sign-ins. Это НЕ означает, что
   каждый пользователь сможет редактировать чужие карточки: RLS привязывает запись
   к анонимному аккаунту автора.
4. В Project Settings → API Keys скопируйте publishable key (или legacy anon key).
   В Project Settings → API найдите Project URL.
5. В supabase-config.js вставьте URL и публичный ключ. НИКОГДА не используйте
   service_role / secret key в HTML или JS.
6. Загрузите всю папку сайта на HTTPS-хостинг. Откройте сайт в двух браузерах,
   добавьте карточку в первом, обновите страницу во втором — карточка появится.

ПОВЕДЕНИЕ
- Исходные карточки из архива доступны всем, но не редактируются через облако.
- Новые карточки хранятся в Supabase, видны всем; редактирует и удаляет автор.
- При отсутствии связи с базой сохранение новых карточек запрещено, чтобы
  не создавать ложное впечатление, что они опубликованы.
- Личный план, избранное, QR-банк и настройки пока локальные.
- Список обновляется при загрузке страницы и после сохранения; для новых
  записей других пользователей нужно обновить страницу.
- Анонимная авторизация — ПРОТОТИП: очистка данных браузера может привести
  к потере права редактировать свои карточки. Перед публичным запуском
  рекомендуется вход по email и модерация/антиспам.
- Не размещайте личные данные учеников и секреты в публичных карточках.
- Старые пользовательские карточки из localStorage НЕ отправляются автоматически
  в общую базу: необходим отдельный проверяемый импорт.
